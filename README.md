## Overview

Modern cloud systems are vulnerable to privilege escalation, container escapes, and missing security context headers. This toolkit automates:

- **Linux Kernel & Container Runtime Hardening**: Validates seccomp, AppArmor, and readonly root filesystems.
- **Secret & Credential Leak Scanning**: Detects high-entropy strings and uncommitted environment tokens.
- **HTTP Security Header Auditing**: Enforces strict HSTS, CSP, and X-Content-Type-Options compliance matching the 100/100 score standard demonstrated on [xpanzio.com](https://xpanzio.com).
